# Source attribution

codex-discord includes code derived from the public source snapshot of comeran/discord-codex-bridge:
https://github.com/comeran/discord-codex-bridge

The imported implementation provided project bindings, native session reuse, queues, management commands and baseline tests. This repository adds owner/channel restrictions, configurable native runtime, workspace allowlists, final-only replies, image inputs, proxy handling, process controls and generalized documentation.

This notice preserves upstream attribution and does not assert a license grant beyond terms supplied by the upstream authors. Dependency packages retain their respective licenses; generated dependencies are not checked into this repository.
